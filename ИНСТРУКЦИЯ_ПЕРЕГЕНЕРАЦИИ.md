# 🔄 ПРАВИЛЬНАЯ ПЕРЕГЕНЕРАЦИЯ SWAGGER

## ❌ ПРОБЛЕМА:

В `swagger/doc.json` нет `securityDefinitions`, хотя комментарии есть в коде.

**Причина:** Swag генерирует документацию из комментариев, но они должны быть в **одном месте** - в `main.go`.

---

## ✅ РЕШЕНИЕ:

### Шаг 1: Убедитесь, что комментарии только в main.go

Комментарии для Swagger должны быть **только** в `cmd/server/main.go`:
- ✅ `@title`, `@version`, `@description`
- ✅ `@host`, `@BasePath`
- ✅ `@securityDefinitions.apikey BearerAuth`
- ✅ `@in header`
- ✅ `@name Authorization`
- ✅ `@description`

**Удалены дублирующие комментарии из `internal/api/server.go`.**

### Шаг 2: Перегенерируйте документацию

**Запустите скрипт:**

```cmd
cd C:\spa-frontend\SPA_Dep
ПРАВИЛЬНАЯ_ПЕРЕГЕНЕРАЦИЯ.bat
```

**Или вручную:**

```cmd
cd C:\spa-frontend\SPA_Dep

# Установите swag (если еще не установлен)
go install github.com/swaggo/swag/cmd/swag@latest

# Перегенерируйте документацию
swag init -g cmd/server/main.go

# Проверьте, что securityDefinitions появились
findstr "securityDefinitions" docs\swagger.json

# Пересоберите контейнер
docker-compose stop deposits-app
docker-compose build --no-cache deposits-app
docker-compose up -d deposits-app
```

### Шаг 3: Проверьте результат

1. Откройте: http://localhost:3001/swagger/doc.json
2. Найдите `"securityDefinitions"` (Ctrl+F)
3. Должно быть:

```json
"securityDefinitions": {
    "BearerAuth": {
        "type": "apiKey",
        "name": "Authorization",
        "in": "header",
        "description": "Type \"Bearer\" followed by a space and JWT token."
    }
}
```

4. Откройте: http://localhost:3001/swagger/index.html
5. Должна появиться кнопка **"Authorize"** вверху справа

---

## ⚠️ ВАЖНО:

- **Очистите кэш браузера** (Ctrl+Shift+R или режим инкогнито)
- Комментарии Swagger должны быть **только в main.go**
- После изменения комментариев нужно **перегенерировать** через `swag init`

---

```go
// @name Authorization

```

Все комментарии должны быть **перед** функцией `main()`.
