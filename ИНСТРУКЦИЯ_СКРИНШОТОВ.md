  - Результаты фильтрации

**Код для объяснения:**
- Файл: `src/pages/ServicesPage.tsx`
- Строка 11: `const [searchParams, setSearchParams] = useSearchParams()` - работа с URL параметрами
- Строка 14: `const [query, setQuery] = useState(searchParams.get('q') || '')` - чтение фильтра из URL при загрузке
- Строки 82-88: Синхронизация состояния с URL параметрами при навигации
- Строка 99: `setSearchParams({ q: query })` - сохранение фильтра в URL при поиске
- Строка 56: `await getServices(query)` - фильтрация при загрузке
- **Как это работает:** Фильтр сохраняется в URL как параметр `?q=Январь`, поэтому при возврате на страницу он восстанавливается из URL

  2. Откройте DevTools (F12)
  3. Включите режим адаптивного дизайна (Ctrl+Shift+M)
  4. Установите ширину, например, 1920px
- **Что показать на скриншоте:**
  - Широкий экран с несколькими колонками карточек
  - DevTools с указанием ширины экрана

### Скриншот 7: Адаптивный режим (узкий экран)
- **Что делать:**
  1. В том же режиме измените ширину на 375px (мобильный)
  2. Убедитесь, что карточки перестроились в одну колонку
- **Что показать на скриншоте:**
  - Узкий экран с одной колонкой карточек
  - DevTools с указанием ширины 375px

**Код для объяснения:**
- Файл: `src/App.css`
- Строки 297-305: `.cards-grid` - сетка карточек
  ```css
  grid-template-columns: repeat(auto-fit, minmax(300px, 1fr));
  gap: 20px;
  max-width: 1400px;
  ```
  - `minmax(300px, 1fr)` - минимальная ширина карточки 300px
  - `auto-fit` - автоматическое количество колонок
  - `max-width: 1400px` - максимальная ширина контейнера

- Строки 627-693: `@media (max-width: 768px)` - мобильная версия
  ```css
  .cards-grid {
    grid-template-columns: 1fr; /* Одна колонка на мобильных */
  }
  ```
  - На экранах меньше 768px: **1 колонка**
  - На экранах больше 768px: **автоматически** (обычно 2-4 колонки в зависимости от ширины)

- Строки 307-310: Размер карточек
  ```css
  .cards-grid > * {
    max-width: 350px; /* Максимальная ширина карточки */
    width: 100%;
  }
  ```
  - Максимальная ширина карточки: **350px**
  - Минимальная ширина карточки: **300px** (из `minmax`)

  - Консоль с логами бэкенда
  - IP адрес сервера (например, `192.168.1.100:3001`)

### Скриншот 11: IP в коде приложения
- **Что делать:**
  1. Откройте файл `vite.config.ts`
  2. Найдите настройки proxy
  3. Покажите, где можно изменить IP адрес
- **Что показать на скриншоте:**
  - Файл `vite.config.ts` с настройками proxy
  - Строки 12-13: `target: 'http://localhost:3001'`
  - Объяснить, что можно заменить на `http://192.168.1.100:3001`

**Код для объяснения:**
- Файл: `vite.config.ts`
- Строки 9-23: Настройки proxy
  ```typescript
  proxy: {
    '/api': {
      target: 'http://localhost:3001', // Можно заменить на IP
      changeOrigin: true,
      secure: false,
    },
    '/images': {
      target: 'http://localhost:3001', // Можно заменить на IP
      changeOrigin: true,
      secure: false,
    },
  }
  ```

### Скриншот 12: Подключение по IP в Tauri

## 9️⃣ HTTPS В ЛОКАЛЬНОМ ФРОНТЕНДЕ

### Скриншот 16: Настройка HTTPS
- **Что делать:**
  1. Установите `mkcert`: `choco install mkcert` (Windows) или `brew install mkcert` (Mac)
  2. Создайте локальный CA: `mkcert -install`
  3. Создайте сертификат: `mkcert localhost 127.0.0.1`
  4. Настройте Vite для использования HTTPS
- **Что показать на скриншоте:**
  - Команды для установки и настройки
  - Файлы сертификатов (`.pem`)

**Настройка Vite:**
- Файл: `vite.config.ts`
- Добавить:
  ```typescript
  server: {
    https: {
      key: fs.readFileSync('localhost-key.pem'),
      cert: fs.readFileSync('localhost.pem'),
    },
    // ...
  }
  ```

### Скриншот 17: HTTPS в браузере
- **Что делать:**
  1. Запустите dev сервер: `npm run dev`
  2. Откройте: `https://localhost:5173`
  3. Убедитесь, что соединение защищено (замочек в адресной строке)
- **Что показать на скриншоте:**
  - Браузер с `https://localhost:5173`
  - Замочек в адресной строке (HTTPS)
  - DevTools → Security → показать информацию о сертификате
