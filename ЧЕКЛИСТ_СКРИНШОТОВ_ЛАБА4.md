# 📸 ЧЕКЛИСТ СКРИНШОТОВ ДЛЯ ЛАБЫ 4 (SPA_Dep)

### **1. Аутентификация через Swagger (режим инкогнито)**

**Действия:**
1. Откройте браузер в режиме инкогнито (Ctrl+Shift+N)
2. Перейдите: http://localhost:3001/swagger/index.html
3. Найдите `POST /auth/login` или `POST /auth/register`
4. Выполните запрос с данными:
   ```json
   {
     "email": "user@example.com",
     "password": "password123"
   }
   ```
5. Получите JWT токен из ответа

**Скриншот должен показать:**
- ✅ Swagger UI в режиме инкогнито
- ✅ Запрос `POST /auth/login` или `/auth/register`
- ✅ Request body
- ✅ Response с JWT токеном (поле `token`)
- ✅ Данные пользователя

**Сохраните JWT токен!**

---

### **2. Получение списка заявок через Swagger**

**Действия:**
1. В Swagger нажмите "Authorize" (замочек)
2. Вставьте JWT токен: `Bearer <ваш_токен>`
3. Выполните `GET /requests`

**Скриншот должен показать:**
- ✅ Swagger с авторизацией (замочек зеленый)
- ✅ Запрос `GET /requests`
- ✅ Response со списком заявок
- ✅ Статус 200 OK

- ✅ Headers с Authorization или Cookie

### **9. Redis через CMD (сессии)**

**Действия:**
1. CMD/PowerShell:
   ```cmd
   docker exec -it redis redis-cli
   ```
2. В Redis CLI:
   ```redis
   KEYS *
   GET token:user@example.com
   HGETALL session:user:1
   ```

**Скриншот должен показать:**
- ✅ CMD/PowerShell с подключением к Redis
- ✅ Команда `KEYS *` - список ключей
- ✅ Команда `GET token:...` - JWT токен
- ✅ Команда `HGETALL session:user:...` - данные сессии (email, role, login_at)

**Важно:** Покажите структуру данных в Redis!
