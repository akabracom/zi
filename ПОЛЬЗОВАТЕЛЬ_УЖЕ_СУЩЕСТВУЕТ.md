# ✅ ПОЛЬЗОВАТЕЛЬ УЖЕ СУЩЕСТВУЕТ

## ❌ ОШИБКА:

```
ERROR: duplicate key value violates unique constraint "users_email_key"
```

Это значит, что пользователь с email `user@example.com` **уже существует** в БД!

---

## ✅ РЕШЕНИЕ: Просто войдите!

Пользователь уже создан (вероятно, через миграции). Просто войдите через `POST /auth/login`:

### В Swagger:

1. Найдите endpoint `POST /auth/login`
2. Выполните запрос:

```json
{
  "email": "user@example.com",
  "password": "password123"
}
```

3. Получите JWT токен из ответа
4. Готово! Используйте этот токен для авторизации
