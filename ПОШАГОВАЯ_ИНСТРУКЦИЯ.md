## 🌐 ПРОКСИ КУДА СМОТРИТ ФРОНТ (ВАЖНО)

1) Файл `vite.config.ts` (в корне `spa-deposits`):
```ts
server: {
  port: 5173,
  proxy: {
    '/api': {
      target: 'http://localhost:3001', // все API-запросы идут на бэкенд
      changeOrigin: true,
      secure: false,
    },
    '/images': {
      target: 'http://localhost:3001', // картинки тоже через прокси
      changeOrigin: true,
      secure: false,
      ws: false,
    },
  },
}
```

2) Что это значит:
   - Любой запрос фронта к `/api/...` уходит на `http://localhost:3001/api/...`
   - Любой запрос к `/images/...` уходит на `http://localhost:3001/images/...`
   - Браузеру не нужно знать порт 3001 — прокси всё перенаправит

3) **КАК УВИДЕТЬ ПРОКСИ В ДЕЙСТВИИ (ПОШАГОВО):**

   **Шаг 1: Открой DevTools**
   - Нажми **F12** (или правой кнопкой → "Просмотреть код")
   - Перейди на вкладку **Network** (Сеть)

   **Шаг 2: Отфильтруй запросы**
   - В поле поиска вверху введи `api` (чтобы видеть только API-запросы)
   - Или выбери фильтр **Fetch/XHR** (только AJAX-запросы)

   **Шаг 3: Обнови страницу**
   - Нажми **Ctrl+Shift+R** (жесткая перезагрузка)
   - В списке появятся запросы: `services`, `draft`, `service_1.png` и т.д.

   **Шаг 4: Кликни на запрос `services`** (одинарный клик)
   - Откроется панель справа с деталями запроса

   **Шаг 5: Посмотри вкладку "Headers" (Заголовки)**
   - **Request URL**: `http://localhost:5173/api/services` ← Запрос идет на порт 5173 (фронтенд)
   - **General → Request Method**: `GET`
   - **General → Status Code**: `200 OK`
   - **Это и есть прокси!** Запрос идет на `localhost:5173`, но Vite перенаправляет его на `localhost:3001`
   
   **Шаг 6: Посмотри вкладку "Response" (Ответ)**
   - Там будут данные от бэкенда (JSON с услугами)
   - Это доказывает, что запрос дошел до бэкенда через прокси
   
   **Шаг 7: Сравни с прямым запросом (для понимания)**
   - Если бы прокси не было, запрос шел бы напрямую на `http://localhost:3001/api/services`
   - Но в Network видно `localhost:5173/api/services` - это и есть прокси!
   - Браузер делает запрос на 5173, Vite перенаправляет на 3001

   **ВАЖНО: В логах бэкенда прокси НЕ видно!**
   - В логах бэкенда (`docker-compose logs deposits-app`) запросы выглядят как прямые
   - Например: `[GIN] GET /api/services` - это уже запрос, который пришел на порт 3001
   - Прокси работает на стороне Vite (фронтенд), поэтому в логах бэкенда разницы нет
   
   **Прокси видно ТОЛЬКО в DevTools Network на фронтенде!**

4) **Проверка руками:**
   - Открой в браузере: `http://localhost:5173/api/services`
   - Должен вернуться JSON с услугами (если бэкенд запущен)
   - Это работает благодаря прокси - запрос идет на порт 5173, но прокси перенаправляет на 3001
