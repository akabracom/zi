# 🍪 НАСТРОЙКА COOKIE ДЛЯ JWT ТОКЕНА

## ❌ ПРОБЛЕМА:

В DevTools нет cookies для `localhost:3001`, потому что приложение не сохраняет JWT токен в cookie.

**Текущая ситуация:** Токен возвращается только в JSON ответе, но не сохраняется в cookie.

---

## ✅ РЕШЕНИЕ: Добавить сохранение токена в cookie

### Вариант 1: Модифицировать handler для сохранения в cookie

Нужно изменить методы `Login` и `Register` в `internal/handler/handler.go`, чтобы они сохраняли токен в cookie.

---

## 📝 ДЛЯ ДЕМОНСТРАЦИИ:

### Альтернатива: Использовать JWT токен из ответа

Если не хотите менять код, для демонстрации можно:

1. **Показать JWT токен из ответа аутентификации:**
   - В Swagger выполните `POST /auth/login`
   - Скопируйте токен из поля `token` в ответе
   - Покажите этот токен в скриншоте

2. **Или использовать токен в Insomnia/Postman:**
   - Покажите заголовок `Authorization: Bearer <токен>`
   - Это тоже демонстрирует работу с токеном

---

## 🔧 ЕСЛИ НУЖНО ДОБАВИТЬ COOKIE:

Можно модифицировать handler, чтобы сохранять токен в cookie:

```go
// В методе Login после генерации токена:
c.SetCookie(
    "session_token",  // имя cookie
    token,            // значение (JWT токен)
    3600*24,          // время жизни (24 часа в секундах)
    "/",              // путь
    "localhost",      // домен
    false,            // secure (false для localhost)
    true,             // httpOnly (защита от XSS)
)
```

Но это требует изменения кода и пересборки.

---

## ✅ РЕКОМЕНДАЦИЯ ДЛЯ ДЕМОНСТРАЦИИ:

**Для скриншота 3 (Cookie из браузера):**

1. **Вариант 1:** Покажите JWT токен из ответа `POST /auth/login` в Swagger
2. **Вариант 2:** Объясните, что используется JWT токен в заголовке, а не cookie
3. **Вариант 3:** Добавьте сохранение в cookie (требует изменения кода)

---

## 🎯 БЫСТРОЕ РЕШЕНИЕ:

Для демонстрации покажите:
- JWT токен из ответа аутентификации в Swagger
- Использование токена в заголовке `Authorization: Bearer <токен>` в Insomnia/Postman

Это демонстрирует работу с JWT токенами, что является стандартной практикой для SPA приложений.
