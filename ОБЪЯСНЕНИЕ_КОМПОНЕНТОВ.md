### 📥 Props (передаваемые данные):

### 🔍 Фильтрация:

```tsx
async function load() {
  setLoading(true)
  setError(null)
  try {
    const data = await getServices(query)  // Передаем query в API
    setServices(data)                      // Обновляем состояние
  } catch (err) {
    setError(err instanceof Error ? err.message : 'Ошибка загрузки месяцев')
  } finally {
    setLoading(false)
  }
}

async function handleSearch(e: React.FormEvent) {
  e.preventDefault()      // Предотвращаем перезагрузку страницы
  await load()            // Вызываем load с текущим query
}
```

**Как работает:**
1. Пользователь вводит текст → `onChange` обновляет `query`
2. Пользователь нажимает "Найти" → `handleSearch` вызывает `load()`
3. `load()` вызывает `getServices(query)` → API запрос с параметром
4. Бэкенд фильтрует данные → возвращает отфильтрованный список
5. `setServices(data)` обновляет состояние → компонент перерисовывается

**В mock режиме:**
- `getServices(query)` вызывает `filterMockServices(query)`
- Фильтрация происходит на клиенте

**В реальном режиме:**
- `getServices(query)` делает `fetch('/api/services?query=...')`
- Фильтрация происходит на бэкенде

---

### 🌐 Вызовы fetch:

```tsx
// В функции load():
const data = await getServices(query)
```

**Цепочка вызовов:**
1. `getServices(query)` → `src/api/http.ts`
2. `apiFetch('/api/services?query=...')` → `src/api/http.ts`
3. `fetch('/api/services?query=...')` → нативный fetch API
4. Vite proxy перенаправляет на `http://localhost:3001/api/services?query=...`
5. Бэкенд обрабатывает запрос → возвращает JSON
6. `apiFetch` парсит JSON → возвращает `Service[]`
7. `setServices(data)` обновляет состояние

---

### 🔄 Жизненный цикл:

1. **Монтирование компонента:**
   ```tsx
   useEffect(() => {
     void load()              // Загружаем список услуг
     void loadCartCount()     // Загружаем количество в корзине
   }, [])                     // Выполняется один раз
   ```

2. **Пользователь вводит текст:**
   ```tsx
   <input
     value={query}
     onChange={(e) => setQuery(e.target.value)}  // Обновляем query
   />
   ```

3. **Пользователь нажимает "Найти":**
   ```tsx
   <form onSubmit={handleSearch}>
     // handleSearch вызывает load() с новым query
   </form>
   ```

4. **Загрузка данных:**
   - `setLoading(true)` → показываем "Загрузка..."
   - `getServices(query)` → делаем запрос
   - `setServices(data)` → обновляем список
   - `setLoading(false)` → скрываем "Загрузка..."

### 🧮 Расчет прибыли:

```tsx
// Извлекаем количество дней из description
function extractDays(description?: string): number {
  if (!description) return 30
  const match = description.match(/Дней:\s*(\d+)/i)
  return match ? parseInt(match[1], 10) : 30
}

// Рассчитываем прибыль: сумма * (ставка/100) * (дней/365)
function calculateProfit(amount: number, rate: number, days: number): number {
  return amount * (rate / 100) * (days / 365)
}

// Расчет итогов с useMemo
const totals = useMemo(() => {
  if (!draft || draft.services.length === 0) {
    return { totalAmount: 0, totalProfit: 0, averageRate: 0 }
  }

  let totalAmount = 0
  let totalProfit = 0
  let totalQuantity = 0
  let weightedSum = 0

  draft.services.forEach((item) => {
    const days = extractDays(item.service.description)
    const itemAmount = depositAmount * item.quantity
    const profit = calculateProfit(depositAmount, item.service.price, days) * item.quantity

    totalAmount += itemAmount
    totalProfit += profit
    totalQuantity += item.quantity
    weightedSum += item.quantity * item.service.price
  })

  const averageRate = totalQuantity > 0 ? weightedSum / totalQuantity : 0

  return { totalAmount, totalProfit, averageRate }
}, [draft])
```

**Объяснение:**
- **`extractDays`** - парсит "Дней: 31" из description через regex
- **`calculateProfit`** - формула расчета прибыли:
  - `amount` - сумма вклада (100 000 руб.)
  - `rate` - процентная ставка (например, 5.5%)
  - `days` - количество дней (например, 31)
  - Формула: `100000 * (5.5/100) * (31/365) = 467.12 руб.`
- **`useMemo`** - пересчитывает только при изменении `draft`
- **Итерация:** для каждой услуги рассчитывает прибыль с учетом количества

## 4. API СЛОЙ - HTTP.TS

### 📍 Файл: `src/api/http.ts`

### 🔧 Функция apiFetch:

```tsx
async function apiFetch<T>(
  path: string,                    // Путь запроса (например, '/api/services')
  options: RequestInit = {},      // Опции fetch (method, body, headers)
  opts?: { auth?: boolean },       // Нужна ли авторизация
): Promise<T> {
  const headers: HeadersInit = {
    ...(options.headers || {}),
  }

  // Добавляем JSON headers для body
  if (options.body && !(options.body instanceof FormData)) {
    Object.assign(headers, JSON_HEADERS)
  }

  // Добавляем Authorization header если нужен
  const needAuth = opts?.auth ?? false
  const token = getToken()
  if (needAuth && token) {
    ;(headers as Record<string, string>).Authorization = `Bearer ${token}`
  }

  // Выполняем fetch запрос
  const response = await fetch(path, {
    ...options,
    headers,
  })

  // Обработка ошибок
  if (!response.ok) {
    const text = await response.text()
    let message = `HTTP ${response.status}`
    try {
      const parsed = JSON.parse(text) as { error?: string }
      if (parsed.error) message = parsed.error
    } catch {
      // ignore
    }
    throw new Error(message)
  }

  // Парсим JSON ответ
  return (await response.json()) as T
}
```

**Объяснение:**
- **Generic `<T>`** - типизированный ответ (TypeScript)
- **Формирование headers:**
  - JSON headers для body (кроме FormData)
  - Authorization header с JWT токеном (если нужен)
- **Вызов fetch:**
  - Использует нативный `fetch` API
  - Путь проксируется через Vite (`/api/*` → `localhost:3001/api/*`)
- **Обработка ошибок:**
  - Проверяет `response.ok`
  - Парсит ошибку из JSON ответа
  - Выбрасывает исключение с понятным сообщением

---

### 🔧 Функция getServices:

```tsx
export function getServices(query?: string): Promise<Service[]> {
  if (USE_MOCK) {
    // Mock режим: возвращаем Promise с задержкой
    return new Promise((resolve) => {
      setTimeout(() => {
        resolve(filterMockServices(query || ''))
      }, 300)
    })
  }
  // Реальный режим: делаем fetch запрос
  const q = query ? `?query=${encodeURIComponent(query)}` : ''
  return apiFetch<Service[]>(`/api/services${q}`, {}, { auth: !!getToken() })
}
```

**Объяснение:**
- **Условная логика:** `USE_MOCK` - переключение между mock и API
- **Mock режим:**
  - Возвращает Promise с задержкой 300ms (имитация сети)
  - Вызывает `filterMockServices(query)` - фильтрация на клиенте
- **Реальный режим:**
  - Формирует URL: `/api/services?query=...`
  - Вызывает `apiFetch` с опциональной авторизацией
  - Бэкенд фильтрует данные

## 5. PROXY КОНФИГУРАЦИЯ

### 📍 Файл: `vite.config.ts`

```typescript
export default defineConfig({
  plugins: [react()],
  server: {
    port: 5173,
    proxy: {
      '/api': {
        target: 'http://localhost:3001',
        changeOrigin: true,
        secure: false,
      },
      '/images': {
        target: 'http://localhost:3001',
        changeOrigin: true,
        secure: false,
        ws: false,
      },
    },
  },
})
```

**Объяснение:**
- **Proxy для `/api`:**
  - Запросы к `http://localhost:5173/api/*` → `http://localhost:3001/api/*`
  - Избегает CORS проблем
  - Прозрачное проксирование
- **Proxy для `/images`:**
  - Запросы к `http://localhost:5173/images/*` → `http://localhost:3001/images/*`
  - Бэкенд получает изображения из MinIO
- **`changeOrigin: true`** - меняет заголовок Origin
- **`secure: false`** - разрешает HTTP (не только HTTPS)

## ✅ КЛЮЧЕВЫЕ МОМЕНТЫ ДЛЯ ОБЪЯСНЕНИЯ

1. **Хуки React:**
   - `useState` - локальное состояние
   - `useEffect` - побочные эффекты (загрузка данных)
   - `useMemo` - мемоизация вычислений
   - `useAuth`, `useRole` - глобальное состояние из Context

2. **Props:**
   - Компоненты не принимают props напрямую
   - Используют Context для глобального состояния
   - Используют Router для навигации

3. **Фильтрация:**
   - В mock режиме - на клиенте (`filterMockServices`)
   - В реальном режиме - на бэкенде (query параметр)

4. **Fetch запросы:**
   - Все идут через `apiFetch` → `fetch`
   - Проксируются через Vite на бэкенд
   - Авторизация через JWT токен в localStorage

5. **Proxy:**
   - Прозрачное проксирование `/api/*` и `/images/*`
   - Избегает CORS проблем
   - Единый домен для фронтенда и API
