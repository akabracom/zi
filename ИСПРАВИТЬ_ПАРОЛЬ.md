# 🔧 ИСПРАВЛЕНИЕ ПАРОЛЯ ПОЛЬЗОВАТЕЛЯ

## ❌ ПРОБЛЕМА:

Пользователь `user@example.com` существует, но пароль не совпадает (401 при входе).

**Причина:** Хеш пароля в БД не совпадает с паролем `password123`.

---

## ✅ РЕШЕНИЕ 1: Обновить пароль в БД (РЕКОМЕНДУЕТСЯ)

### Через Adminer:

1. Откройте: http://localhost:8080
2. Войдите: user / password / deposits
3. Выполните SQL:

```sql
-- Обновить пароль для user@example.com
-- Пароль: password123
-- Хеш: $2a$10$N9qo8uLOickgx2ZMRZoMyeIjZAgcfl7p92ldGxad68LJZdL17lhWy
UPDATE users 
SET password = '$2a$10$N9qo8uLOickgx2ZMRZoMyeIjZAgcfl7p92ldGxad68LJZdL17lhWy' 
WHERE email = 'user@example.com';

-- Обновить пароль для moderator@example.com
UPDATE users 
SET password = '$2a$10$N9qo8uLOickgx2ZMRZoMyeIjZAgcfl7p92ldGxad68LJZdL17lhWy' 
WHERE email = 'moderator@example.com';

-- Проверка
SELECT id, email, name, role FROM users;
```

4. Теперь попробуйте войти через Swagger:
   - Email: `user@example.com`
   - Password: `password123`

---

## ✅ РЕШЕНИЕ 2: Удалить и создать заново через API

### Шаг 1: Удалить старого пользователя

В Adminer выполните:

```sql
DELETE FROM users WHERE email = 'user@example.com';
```

### Шаг 2: Создать нового через Swagger

1. Откройте Swagger: http://localhost:3001/swagger/index.html
2. `POST /auth/register`:

```json
{
  "email": "user@example.com",
  "password": "password123",
  "name": "Test User"
}
```

3. Получите JWT токен
4. Войдите через `POST /auth/login`

---

## ✅ РЕШЕНИЕ 3: Создать нового пользователя с другим email

Если не хотите удалять старого, создайте нового:

1. В Swagger: `POST /auth/register`:

```json
{
  "email": "newuser@example.com",
  "password": "password123",
  "name": "New User"
}
```

2. Войдите с этим email

---

## 🔍 ПРОВЕРКА ХЕША ПАРОЛЯ

Если хотите проверить текущий хеш в БД:

```sql
SELECT email, 
       LEFT(password, 20) as password_start,
       LENGTH(password) as password_length
FROM users;
```

**Правильный хеш для `password123`:**
- Должен начинаться с: `$2a$10$N9qo8uLOickgx2ZMRZoMyeIjZAgcfl7p92ldGxad68LJZdL17lhWy`
- Длина: 60 символов
