# ⚡ БЫСТРОЕ ИСПРАВЛЕНИЕ ПУСТОЙ СТРАНИЦЫ

## 🔍 ЧТО ПРОВЕРИТЬ ПРЯМО СЕЙЧАС

### 1. Проверьте Actions (самое важное!)

Откройте: **https://github.com/akabracom/zi/actions**

- ✅ **Зеленая галочка** = все хорошо, но сайт не работает → смотрите пункт 2
- ❌ **Красный крестик** = есть ошибки → откройте и посмотрите логи
- ⏳ **Желтый кружок** = еще выполняется → подождите 2-3 минуты

---

### 2. Проверьте настройки Pages

Откройте: **https://github.com/akabracom/zi/settings/pages**

Убедитесь, что:
- **Source:** `Deploy from a branch`
- **Branch:** `tauri-deposits` (или `spa-deposits` для 5 лабы)
- **Folder:** `/ (root)`

**Нажмите Save!**

---

### 3. Проверьте консоль браузера

1. Откройте `akabracom.github.io/zi/`
2. Нажмите **F12**
3. Вкладка **Console** → есть ли красные ошибки?

**Частые ошибки:**
- `404` на `.js` файлы → проблема с `base: '/zi/'`
- `Cannot find module` → проблема со сборкой

---

### 4. Перезапустите deployment

**Вариант А (через GitHub):**
1. Откройте: https://github.com/akabracom/zi/actions
2. Найдите последний workflow
3. Нажмите **Re-run all jobs**

**Вариант Б (через Git):**
```bash
cd C:\spa-frontend\lab6\spa-deposits-tauri
git commit --allow-empty -m "Trigger deployment"
git push origin tauri-deposits
```

---

### 5. Проверьте конфигурацию

**Для 6 лабы (`tauri-deposits`):**

`vite.config.ts`:
```typescript
base: '/zi/', // ДОЛЖНО БЫТЬ!
```

`src/App.tsx`:
```typescript
<BrowserRouter basename={import.meta.env.BASE_URL || '/zi/'}>
```

**Для 5 лабы (`spa-deposits`):**

`vite.config.ts`:
```typescript
// БЕЗ base!
```

`src/App.tsx`:
```typescript
<BrowserRouter> // БЕЗ basename!
```

## ✅ ЧТО СДЕЛАТЬ СЕЙЧАС

1. **Откройте Actions:** https://github.com/akabracom/zi/actions
2. **Посмотрите статус** последнего workflow
3. **Если есть ошибки** → откройте и скопируйте текст ошибки
4. **Если все зеленое** → проверьте настройки Pages (пункт 2)
5. **Перезапустите deployment** (пункт 4)
