# 🚀 БЫСТРОЕ СОЗДАНИЕ ПОЛЬЗОВАТЕЛЯ

## Вариант 1: Через Swagger (САМЫЙ БЫСТРЫЙ)

1. Откройте: http://localhost:3001/swagger/index.html
2. Найдите `POST /auth/register`
3. Выполните запрос:

```json
{
  "email": "user@example.com",
  "password": "password123",
  "name": "Test User"
}
```

4. Получите JWT токен из ответа
5. Готово! Теперь можно войти через `POST /auth/login`

---

## Вариант 2: Через Adminer (SQL)

1. Откройте: http://localhost:8080
2. Войдите: user / password / deposits
3. Выполните SQL из файла `СОЗДАТЬ_ПОЛЬЗОВАТЕЛЕЙ.sql`

---

## Вариант 3: Через командную строку

```cmd
cd C:\spa-frontend\SPA_Dep
docker exec -it deposits-db psql -U user -d deposits -f /docker-entrypoint-initdb.d/01_users.sql
```
