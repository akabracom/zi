# 🔧 ИСПРАВЛЕНИЕ ПРОБЛЕМЫ С ИЗОБРАЖЕНИЯМИ

## ❌ ПРОБЛЕМА

В mock режиме изображения не загружаются, потому что:
- Бэкенд не запущен
- URL `http://localhost:3001/images/january.png` недоступен
- Изображения показывают ошибку загрузки

## ✅ РЕШЕНИЕ

Исправлен код в `src/pages/ServicesPage.tsx`:

1. **Добавлена проверка mock режима:**
   ```tsx
   const USE_MOCK = import.meta.env.VITE_USE_MOCK === 'true' || false
   ```

2. **Условное отображение изображений:**
   - **В реальном режиме:** изображения загружаются через бэкенд из MinIO
   - **В mock режиме:** используются placeholder изображения через `via.placeholder.com` с названием месяца
   - **При ошибке загрузки:** автоматически показывается placeholder

## 📝 ИЗМЕНЕНИЯ В КОДЕ

### До:
```tsx
{s.image_url && (
  <img
    src={s.image_url.startsWith('http') 
      ? s.image_url 
      : `http://localhost:3001/images/${s.image_url.replace(/^(img\/|images\/|deposits\/img\/)/, '')}`}
    alt={s.name}
    className="service-image"
  />
)}
```

### После:
```tsx
{s.image_url && (
  <img
    src={USE_MOCK 
      ? `https://via.placeholder.com/300x150/4A90E2/FFFFFF?text=${encodeURIComponent(s.name)}`
      : s.image_url.startsWith('http') 
        ? s.image_url 
        : `http://localhost:3001/images/${s.image_url.replace(/^(img\/|images\/|deposits\/img\/)/, '')}`}
    alt={s.name}
    className="service-image"
    onError={(e) => {
      console.error('Failed to load image:', s.image_url, 'Full URL:', e.currentTarget.src)
      // В случае ошибки используем placeholder
      if (!USE_MOCK) {
        e.currentTarget.src = `https://via.placeholder.com/300x150/CCCCCC/666666?text=${encodeURIComponent(s.name)}`
      }
    }}
  />
)}
```

## 🚀 КАК ПРОВЕРИТЬ

### Mock режим:
1. Убедитесь, что `.env` содержит: `VITE_USE_MOCK=true`
2. Перезапустите dev server: `npm run dev`
3. Откройте: http://localhost:5173
4. Должны быть видны placeholder'ы вместо изображений

### Реальный режим:
1. Убедитесь, что `.env` содержит: `VITE_USE_MOCK=false` (или удалите `.env`)
2. Запустите бэкенд: `cd SPA_Dep && docker-compose up -d deposits-app`
3. Перезапустите dev server: `npm run dev`
4. Откройте: http://localhost:5173
5. Изображения должны загружаться из MinIO через бэкенд
