## 🔧 ШАГ 1: ПРОВЕРКА ЛОГОВ

Выполните в командной строке:

```cmd
cd C:\spa-frontend\SPA_Dep
docker-compose logs deposits-app --tail=50
```

Или для PowerShell:

```powershell
cd C:\spa-frontend\SPA_Dep
docker-compose logs deposits-app --tail=50
```

**Что искать в логах:**
- Ошибки подключения к БД
- Ошибки Redis
- Ошибки валидации пароля
- Ошибки JWT

---

## 🔧 ШАГ 2: ПРОВЕРКА ПОЛЬЗОВАТЕЛЕЙ В БД

### Через Adminer:

1. Откройте: http://localhost:8080
2. Войдите: user / password / deposits
3. Выполните SQL:

```sql
-- Проверка пользователей
SELECT id, email, name, role, 
       LENGTH(password) as password_length,
       LEFT(password, 10) as password_preview
FROM users;
```

**Ожидаемый результат:**
- Должны быть пользователи: `user@example.com` и `moderator@example.com`
- Пароль должен быть длинным (bcrypt хеш ~60 символов)
- `password_preview` должен начинаться с `$2a$10$`

---

## 🔧 ШАГ 3: ПРОВЕРКА ПАРОЛЯ

Если пароль не совпадает, возможно проблема с хешированием.

### Вариант 1: Создать нового пользователя через API

В Swagger выполните `POST /auth/register` с **НОВЫМ** email:

```json
{
  "email": "newuser@example.com",
  "password": "password123",
  "name": "New User"
}
```

Затем войдите с этим email.

### Вариант 2: Обновить пароль существующего пользователя

В Adminer выполните SQL (создаст новый хеш):

```sql
-- ВНИМАНИЕ: Это создаст новый хеш для пароля "password123"
-- Нужно будет использовать bcrypt для генерации хеша
-- Или просто создать нового пользователя через API
```

**Лучше:** Создать нового пользователя через API.

---

## 🔧 ШАГ 4: ПРОВЕРКА REDIS

Проверьте, работает ли Redis:

```cmd
docker exec -it redis redis-cli PING
```

Должен вернуть: `PONG`

Если Redis не работает, это может вызывать ошибки при сохранении токенов.

---

## 🔧 ШАГ 5: ПРОВЕРКА ПОДКЛЮЧЕНИЯ К БД

Проверьте, что приложение подключено к БД:

```cmd
docker exec -it deposits-app sh -c "echo 'SELECT COUNT(*) FROM users;' | psql -h deposits-db -U user -d deposits"
```

---

## ✅ БЫСТРОЕ РЕШЕНИЕ: СОЗДАТЬ НОВОГО ПОЛЬЗОВАТЕЛЯ

Если ничего не помогает, создайте нового пользователя через API:

1. В Swagger: `POST /auth/register`
2. Используйте **НОВЫЙ** email (не `user@example.com`):

```json
{
  "email": "testuser@example.com",
  "password": "password123",
  "name": "Test User"
}
```

3. Получите JWT токен
4. Войдите через `POST /auth/login` с теми же данными
